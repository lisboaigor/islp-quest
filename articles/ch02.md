> [!key] **Em uma frase.** Aprender com dados é encontrar uma função que descreva a relação entre entradas e saída; o desafio é que a função mais fiel aos dados que você tem **não é** a que melhor prevê dados novos.

Este capítulo é a base de todos os outros. Se você entender bem as quatro ideias abaixo, o resto do livro vira variações delas: **estimar $f$**, **erro de treino contra erro de teste**, **viés contra variância**, e **classificação com Bayes e KNN**.

## 2.1 O que é aprender uma função

Imagine que você presta consultoria para uma empresa. Ela vende um produto em 200 cidades e investe em propaganda de TV, rádio e jornal. Ela não controla as vendas diretamente, mas controla o dinheiro de cada mídia. Você quer descobrir como as vendas dependem dos três investimentos.

Os investimentos são as **entradas** (ou preditores), que chamamos de $X_1,X_2,X_3$. As vendas são a **resposta**, $Y$. A hipótese geral do livro é que existe alguma relação:

$$Y = f(X) + \varepsilon$$

Leia assim: "a resposta é uma **parte sistemática** $f(X)$ mais um **ruído** $\varepsilon$". A função $f$ é o padrão que existe de verdade, mas ninguém conhece. O ruído $\varepsilon$ reúne tudo que muda as vendas e que não está nos dados (o clima, a concorrência, a sorte), e ele não depende de $X$.

Todo o livro é sobre uma pergunta: **como estimar $f$ a partir dos dados?**

### 2.1.1 Por que estimar $f$: prever ou explicar

*Veja no livro: Figuras 2.1, 2.2 e 2.3.*

Existem dois motivos, e a escolha muda como você trabalha.

**Previsão.** Você tem $X$ e quer adivinhar $Y$. Aqui o modelo pode ser uma **caixa-preta**: se acerta, não importa como funciona por dentro. Exemplo: prever se um paciente terá reação grave a um remédio, a partir de exames de sangue.

**Inferência.** Você quer entender **como** $Y$ depende de $X$. Quais entradas importam? A relação é positiva ou negativa? É uma reta ou uma curva? Aqui o modelo **não pode** ser caixa-preta, porque a forma dele é a resposta.

> [!key] Se você só quer prever, interpretabilidade é opcional. Se quer explicar, é o ponto principal. Muitos problemas reais misturam os dois.

#### O erro que nunca some

Mesmo um modelo excelente erra. Há dois tipos de erro, e saber separá-los evita muita frustração.

O **erro redutível** vem de o seu modelo $\hat f$ não ser exatamente $f$. Um método melhor pode diminuí-lo.

O **erro irredutível** vem do ruído $\varepsilon$. Nenhum método, por melhor que seja, consegue prever o que as entradas não explicam.

Com $X$ e $\hat f$ fixos, a conta fica assim:

$$E\big(Y-\hat Y\big)^2 = \underbrace{\big[f(X)-\hat f(X)\big]^2}_{\text{redutível}} + \underbrace{\operatorname{Var}(\varepsilon)}_{\text{irredutível}}$$

> [!warn] **Cuidado.** O erro irredutível é um **piso**: o erro nunca fica abaixo dele. Na prática, você quase nunca sabe qual é esse piso. Por isso "o erro ainda é grande" não quer dizer que o modelo é ruim: pode ser o ruído mesmo.

> [!lab] **Para o caderno.** Antes de seguir, responda sem olhar: se você soubesse $f$ exatamente, o erro de previsão seria zero? (Resposta curta: não, e a missão desta seção pede para você provar por quê.) Missão: [Por que estimar f](/l/ch02-estimar-f).

### 2.1.2 Como estimar $f$: paramétrico e não paramétrico

*Veja no livro: Figuras 2.4, 2.5 e 2.6.*

Existem duas grandes estratégias.

Nos métodos **paramétricos** você faz uma aposta: "acho que $f$ é uma reta". Escreve a forma, por exemplo $f(X)=\beta_0+\beta_1X_1+\dots+\beta_pX_p$, e então só precisa **ajustar os números** $\beta$ usando os dados. O problema fica fácil: estimar $p+1$ números em vez de uma função inteira. O risco é que a aposta esteja errada.

Nos **não paramétricos** você não aposta em forma nenhuma. O método se adapta ao que os dados mostram, o que é ótimo se a relação for complicada. O preço é que ele precisa de **muitos dados** para fazer isso bem.

Existe ainda um perigo que vale nos dois casos, o **overfitting** (sobreajuste): o modelo segue o ruído dos dados de treino como se fosse padrão. Ele fica lindo nos dados que viu e ruim nos novos.

> [!deep] **No livro.** A Figura 2.6 mostra uma curva flexível que passa por todos os pontos de treino e mesmo assim erra feio fora deles (p. 23). É a imagem do overfitting.

### 2.1.3 Interpretabilidade contra flexibilidade

*Veja no livro: Figura 2.7.*

Métodos **restritos** produzem poucas formas (uma reta, por exemplo) e são fáceis de interpretar. Métodos **flexíveis** produzem formas muito variadas, ajustam melhor, mas ficam difíceis de explicar.

Do mais fácil de interpretar ao mais difícil: seleção de variáveis e lasso, depois mínimos quadrados, depois modelos aditivos e árvores, depois bagging, boosting e SVM, e por fim redes neurais (deep learning).

> [!warn] **Contraintuitivo.** Se você só quer prever, o método mais flexível **não** é automaticamente o melhor. Muitas vezes um método mais simples prevê melhor justamente porque não decora o ruído. A seção 2.2 explica por quê.

### 2.1.4 Supervisionado ou não

*Veja no livro: Figura 2.8.*

No **aprendizado supervisionado**, cada observação traz a entrada e a resposta correta, e você aprende a relação. No **não supervisionado**, só há entradas, e você procura estrutura, como grupos de clientes parecidos. Existe ainda um meio-termo, o **semissupervisionado**, em que só parte dos dados tem resposta.

### 2.1.5 Regressão ou classificação

Se a resposta é um **número** (preço, salário), é **regressão**. Se é uma **categoria** (spam ou não, tipo de tumor), é **classificação**.

> [!warn] O nome engana. A **regressão logística** é um método de classificação: ela estima a probabilidade de cada classe. E o KNN serve para os dois casos. Escolha o método pelo tipo da **resposta**, não pelo nome.

## 2.2 Medir se o modelo é bom

### 2.2.1 Erro de treino e erro de teste

*Veja no livro: Figuras 2.9, 2.10 e 2.11.*

Em regressão, a medida padrão é o **erro quadrático médio (MSE)**:

$$\text{MSE}=\frac1n\sum_{i=1}^n\big(y_i-\hat f(x_i)\big)^2$$

Em palavras: para cada observação, veja o quanto a previsão errou, eleve ao quadrado (para que erros para cima e para baixo não se cancelem), e tire a média.

Há uma armadilha importante. Se você calcula esse número nos mesmos dados que usou para ajustar o modelo, tem o **MSE de treino**. Ele responde "quão bem o modelo decorou o que viu?". Mas o que interessa é o **MSE de teste**: o erro em dados **novos**, que o modelo nunca viu.

> [!key] **A ideia mais importante do capítulo.** Erro de treino não escolhe modelo. Conforme o modelo fica mais flexível, o erro de treino **sempre cai**. Já o erro de teste cai no começo e depois **sobe**, formando um U. O melhor modelo é o do fundo do U, não o mais flexível.

Por isso, quando você tem poucos dados para testar, usa técnicas que fingem separar dados novos, a **validação cruzada** (Capítulo 5).

### 2.2.2 Viés e variância

*Veja no livro: Figura 2.12.*

Por que o erro de teste faz um U? Porque ele é a soma de três ingredientes. Num ponto $x_0$:

$$E\big(y_0-\hat f(x_0)\big)^2=\operatorname{Var}\big(\hat f(x_0)\big)+\big[\operatorname{Bias}\big(\hat f(x_0)\big)\big]^2+\operatorname{Var}(\varepsilon)$$

Os três termos, um por um:

**Variância** é quanto o seu modelo **muda** se você treinasse de novo com outros dados. Se um único ponto trocado já muda muito a curva, a variância é alta. Modelos flexíveis têm variância alta.

**Viés** é o erro **sistemático** de usar um modelo simples demais para um problema complicado. Se a verdade é uma curva e você ajusta uma reta, a reta erra sempre do mesmo jeito. Modelos flexíveis têm viés baixo.

**Ruído** $\operatorname{Var}(\varepsilon)$ é o erro irredutível de antes.

> [!key] **O dilema.** Aumentar a flexibilidade **diminui o viés e aumenta a variância**. No início o viés cai mais rápido, e o erro desce. Depois a variância pesa mais, e o erro sobe. É o U. E como as três parcelas não são negativas, o erro de teste nunca fica abaixo do ruído.

Uma imagem útil é um alvo de dardos. Viés é o centro dos seus dardos estar longe do alvo. Variância é os dardos estarem espalhados. Dá para ter qualquer combinação: uma reta horizontal fixa tem variância zero e viés enorme; uma curva que passa por todos os pontos tem viés baixo e variância enorme.

### 2.2.3 Classificação: Bayes e KNN

*Veja no livro: Figuras 2.13, 2.14, 2.15, 2.16 e 2.17.*

Em classificação, a medida de erro é a **taxa de erro**: a fração de observações classificadas errado. Vale a mesma lição: o que importa é a taxa em dados de **teste**.

O melhor classificador possível, que ninguém tem na prática, é o **classificador de Bayes**: para cada ponto, escolha a classe mais provável dado $X$:

$$\Pr(Y=j\mid X=x_0)\ \text{(escolha o } j \text{ com maior valor)}$$

Em duas classes, isso é escolher a classe 1 se a probabilidade passar de 0,5. A menor taxa de erro possível é a **taxa de erro de Bayes**. Ela é maior que zero quando as classes se misturam, e é o equivalente do erro irredutível da regressão.

Como nunca conhecemos essas probabilidades, o **KNN** (K vizinhos mais próximos) as estima olhando para os $K$ pontos de treino mais próximos de $x_0$ e usando a fração de cada classe entre eles.

O número $K$ é o botão de flexibilidade:

- **K pequeno** (K=1): fronteira recortada e muito flexível; viés baixo, variância alta. O erro de treino é zero, mas isso não diz nada sobre dados novos.
- **K grande**: fronteira suave, quase uma reta; variância baixa, viés alto.

No exemplo do livro, K=1 e K=100 erram 17% e 19% em dados de teste, enquanto K=10 erra 13,6%, bem perto do mínimo possível (erro de Bayes de 13,0%).

## Vocabulário

| Termo | Em palavras simples |
|---|---|
| $f$ | O padrão verdadeiro (desconhecido) entre entradas e saída |
| $\hat f$ | A estimativa que o seu método produz |
| $\varepsilon$ | Ruído: o que as entradas não explicam |
| Erro redutível | Parte do erro que um método melhor poderia tirar |
| Erro irredutível | O piso: ruído que nenhum método remove |
| Paramétrico | Você aposta numa forma e ajusta números |
| Não paramétrico | Você não aposta em forma; precisa de muitos dados |
| Overfitting | Decorar o ruído do treino |
| MSE de treino / de teste | Erro nos dados vistos / nos dados novos |
| Viés | Erro sistemático por modelo simples demais |
| Variância | Quanto o modelo muda com outros dados de treino |
| Erro de Bayes | Menor taxa de erro possível em classificação |
| KNN | Classifica pela votação dos $K$ vizinhos mais próximos |
