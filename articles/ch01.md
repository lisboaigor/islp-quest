> [!key] **Em uma frase.** Aprendizado estatístico é um conjunto de ferramentas para **entender dados**: prever uma coisa a partir de outras, ou descobrir estrutura quando não há nada para prever.

## Três problemas para guardar na cabeça

*Veja no livro: Figuras 1.1, 1.2 e 1.4.*

O livro abre com três conjuntos de dados que voltam em quase todos os capítulos. Vale aprender os nomes agora, porque depois você os reconhece de longe.

**Wage (salário).** São dados de renda de homens numa região dos Estados Unidos. A pergunta é como o salário muda com a idade, a escolaridade e o ano. A resposta que queremos entender é um **número** (o salário). Quando a resposta é numérica, o problema é de **regressão**.

**Smarket (mercado de ações).** São os retornos diários de um índice da bolsa. A pergunta é: amanhã o índice sobe ou desce? Agora a resposta é uma **categoria** (sobe ou desce). Isso é **classificação**.

**NCI60 (genes).** São medidas de expressão de milhares de genes em 64 linhagens de células de câncer. Aqui ninguém disse qual é a "resposta certa": queremos só ver se as linhagens se agrupam em famílias parecidas. Sem resposta para prever, é **aprendizado não supervisionado**.

> [!key] **Regra de bolso.** Pergunte primeiro: *existe algo que eu quero prever ou explicar?* Se sim, é supervisionado. Depois pergunte: *é um número ou uma categoria?* Número é regressão, categoria é classificação. Se não existe nada para prever, é não supervisionado.

## Um pouco de história, só para situar

A ideia é antiga. O método de **mínimos quadrados**, que é a base da regressão linear, surgiu no início do século XIX, aplicado à astronomia. Para prever categorias, a análise discriminante linear apareceu em 1936 e a regressão logística nos anos 1940. Os métodos mais flexíveis, como árvores, modelos aditivos e redes neurais, só decolaram nos anos 1980, quando os computadores ficaram rápidos o bastante. Máquinas de vetores de suporte vieram nos anos 1990.

Hoje o que mudou foi o acesso: com Python e pacotes prontos, qualquer pessoa consegue ajustar esses modelos. O livro existe para que você entenda **o que está fazendo** ao apertar o botão.

## Vocabulário

| Termo | Em palavras simples |
|---|---|
| Preditor, variável de entrada, *feature* | O que você usa para prever (idade, orçamento de TV) |
| Resposta | O que você quer prever (salário, vendas) |
| Regressão | Resposta é um número |
| Classificação | Resposta é uma categoria |
| Supervisionado | Há resposta conhecida nos dados de treino |
| Não supervisionado | Não há resposta; procuramos padrões |
