> [!key] **Em uma frase.** Sem uma resposta para prever, o trabalho é **explorar**: resumir muitas variáveis em poucas (PCA) ou descobrir grupos de observações parecidas (clustering).

## 12.1 O desafio do não supervisionado

No aprendizado supervisionado você sabe se acertou, porque há uma resposta e dá para medir o erro. Aqui, **não há como verificar** o resultado contra uma verdade. Isso torna a análise mais subjetiva e exploratória, e exige cuidado ao tirar conclusões. Ela é muito usada como etapa anterior: olhar os dados antes de modelar.

## 12.2 Análise de componentes principais (PCA)

Com 50 variáveis, não dá para olhar um gráfico de cada par. O PCA encontra **poucas direções** que carregam a maior parte da variação.

### 12.2.1 O que são componentes principais

*Veja no livro: Figuras 12.1 e 12.2.*

Com as variáveis centradas, a **primeira componente** é a combinação linear com a **maior variância**:

$$Z_1=\phi_{11}X_1+\phi_{21}X_2+\dots+\phi_{p1}X_p,\qquad \sum_j\phi_{j1}^2=1$$

Os $\phi_{j1}$ são as **cargas**. A segunda componente tem a maior variância entre as combinações **perpendiculares** (não correlacionadas) à primeira, e assim por diante.

### 12.2.2 Outra interpretação

As componentes também definem o plano (ou hiperplano) **mais próximo** das observações. As duas interpretações (maior variância e menor distância) são equivalentes.

### 12.2.3 Proporção de variância explicada

*Veja no livro: Figura 12.3.*

$$\text{PVE}_m=\frac{\text{variância de }Z_m}{\text{variância total}}$$

A soma de todas as PVE é 1. O **gráfico de cotovelo** (*scree plot*) ajuda a decidir quantas componentes manter: procure o ponto em que o ganho de PVE cai.

### 12.2.4 Mais sobre PCA

*Veja no livro: Figura 12.4.*

Duas precauções. **Padronize** as variáveis se tiverem escalas diferentes (senão a de maior variância domina). E cada componente é única só a menos do **sinal**: $\phi$ e $-\phi$ descrevem a mesma direção.

### 12.2.5 Outros usos

As componentes podem servir como preditores em regressão (PCR, Capítulo 6) e para visualização.

## 12.3 Valores ausentes e completar matrizes

*Veja no livro: Figuras 12.5 e 12.6.*

Dados reais têm buracos. Uma forma de preenchê-los é supor que a matriz de dados é aproximada por poucas componentes: preenche-se com a melhor aproximação de **posto baixo**, alternando entre estimar as componentes e preencher os buracos. É a base de sistemas de recomendação.

## 12.4 Métodos de agrupamento

### 12.4.1 K-médias

*Veja no livro: Figuras 12.7, 12.8 e 12.9.*

Você escolhe $K$. O objetivo é dividir as observações em $K$ grupos de modo que a distância dentro de cada grupo seja pequena. O algoritmo:

1. Atribua cada observação a um grupo **ao acaso**.
2. Repita até estabilizar: calcule o **centróide** (média) de cada grupo; reatribua cada ponto ao centróide mais próximo.

A cada passo o objetivo **nunca piora**, então o algoritmo converge, mas pode parar num **mínimo local**. Por isso roda-se várias vezes com inícios diferentes e fica-se com o melhor.

### 12.4.2 Agrupamento hierárquico

*Veja no livro: Figuras 12.10, 12.11, 12.13 e 12.14.*

Não exige escolher $K$ de antemão. Começa com cada ponto como um grupo e funde, passo a passo, os dois grupos **mais próximos**, construindo um **dendrograma**, uma árvore de fusões cuja altura mede a dissimilaridade. Cortar o dendrograma numa altura define os grupos.

O que significa "grupos próximos"? Depende da **ligação**:

- **Simples**: menor distância entre pares de pontos dos dois grupos.
- **Completa**: maior distância entre pares.
- **Média**: média de todas as distâncias.
- **Centróide**: distância entre centróides.

Completa e média costumam produzir dendrogramas mais equilibrados.

### 12.4.3 Questões práticas

*Veja no livro: Figuras 12.15 e 12.16.*

Muitas escolhas mudam o resultado: padronizar ou não, qual dissimilaridade (euclidiana ou de correlação), qual ligação, onde cortar, qual $K$. Não há resposta única, e os grupos devem ser vistos como **hipóteses exploratórias**: confira se são **robustos** (repetindo em subconjuntos dos dados).

> [!warn] Clusters achados não são "verdade". São uma sugestão de estrutura que precisa ser validada com conhecimento do problema.

## Vocabulário

| Termo | Em palavras simples |
|---|---|
| Componente principal | Direção de maior variação dos dados |
| Carga | Peso de cada variável numa componente |
| PVE | Fração da variância explicada por uma componente |
| Gráfico de cotovelo | Gráfico das PVE para escolher quantas componentes usar |
| K-médias | Agrupa em $K$ grupos pelas médias |
| Centróide | Média dos pontos de um grupo |
| Dendrograma | Árvore das fusões do agrupamento hierárquico |
| Ligação | Regra de distância entre grupos |
