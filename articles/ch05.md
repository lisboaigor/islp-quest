> [!key] **Em uma frase.** Quando você não tem dados novos para testar o modelo, **finge** que tem: separa pedaços dos dados, treina no resto e mede o erro no pedaço de fora.

Lembra que o erro de treino mente (Capítulo 2)? O erro que importa é o de teste, mas dados de teste raramente sobram. Este capítulo ensina duas técnicas que **reusam** os mesmos dados de formas inteligentes: a **validação cruzada** e o **bootstrap**.

## 5.1 Validação cruzada

### 5.1.1 Conjunto de validação

*Veja no livro: Figuras 5.1 e 5.2.*

A ideia mais simples: divida as observações ao acaso em duas metades, **treino** e **validação**. Ajuste o modelo no treino e meça o erro na validação.

Funciona, mas tem dois defeitos. O resultado muda bastante conforme a divisão sorteada. E o modelo é treinado com apenas parte dos dados, então tende a **superestimar** o erro que teria com todos.

### 5.1.2 Deixar um de fora (LOOCV)

*Veja no livro: Figura 5.3.*

Para cada observação $i$: treine com as outras $n-1$ e meça o erro nela só. A média dos $n$ erros é a estimativa:

$$\text{CV}_{(n)}=\frac1n\sum_{i=1}^n\text{MSE}_i,\qquad \text{MSE}_i=(y_i-\hat y_i)^2$$

Vantagens: treina com quase tudo (pouco viés) e dá sempre o mesmo resultado. Desvantagem: exige $n$ ajustes.

Mas na regressão linear há um **atalho**: com um único ajuste dá para obter o LOOCV exato,

$$\text{CV}_{(n)}=\frac1n\sum_{i=1}^n\left(\frac{y_i-\hat y_i}{1-h_i}\right)^2$$

onde $h_i$ é a alavancagem de cada ponto (Capítulo 3).

### 5.1.3 K-fold

*Veja no livro: Figuras 5.4 e 5.5.*

Divida os dados em $k$ grupos do mesmo tamanho (os *folds*). Cada grupo serve uma vez de validação, treinando-se nos outros $k-1$. A estimativa é a média dos $k$ erros:

$$\text{CV}_{(k)}=\frac1k\sum_{j=1}^k\text{MSE}_j$$

Na prática, usa-se $k=5$ ou $k=10$. O LOOCV é o caso extremo $k=n$.

> [!lab] **Para o caderno.** Calcule o LOOCV pelo atalho e confira com um ajuste sem uma observação: [Validação, LOOCV e k-fold](/l/ch05-validacao).

### 5.1.4 O equilíbrio entre viés e variância na CV

*Veja no livro: Figura 5.6.*

A estimativa da própria validação cruzada tem viés e variância. O conjunto de validação e o k-fold tendem a **superestimar** um pouco o erro (treinam com menos dados). O LOOCV tem o menor viés, mas **variância alta**: os $n$ modelos são treinados em conjuntos quase idênticos, então seus erros são muito correlacionados, e a média de coisas parecidas varia muito. O k-fold com $k=5$ ou $10$ costuma ser o melhor meio-termo.

### 5.1.5 Validação cruzada em classificação

*Veja no livro: Figuras 5.7 e 5.8.*

A mesma ideia, trocando o erro quadrático pela taxa de erro: $\text{Err}_i=I(y_i\neq\hat y_i)$. Serve para escolher, por exemplo, o grau de um polinômio na logística ou o valor de $K$ no KNN. A curva do erro de CV costuma ter o U que já conhecemos, e o fundo do U indica o nível certo de flexibilidade.

## 5.2 O bootstrap

*Veja no livro: Figuras 5.9, 5.10 e 5.11.*

Às vezes o problema não é medir o erro, e sim medir **a incerteza de uma estimativa**. Qual o erro-padrão da fração ideal a investir em dois ativos? Para a média existe fórmula; para quantidades complicadas, não.

O **bootstrap** resolve sorteando dos próprios dados:

1. Sorteie $n$ observações **com reposição** dos dados originais (uma observação pode aparecer várias vezes).
2. Calcule a estimativa nessa amostra.
3. Repita $B$ vezes.
4. O desvio-padrão das $B$ estimativas é o erro-padrão:

$$\text{SE}_B(\hat\alpha)=\sqrt{\frac{1}{B-1}\sum_{r=1}^B\Big(\hat\alpha^{*r}-\bar{\hat\alpha}^{*}\Big)^2}$$

O exemplo do livro: aplicar uma fração $\alpha$ do dinheiro num ativo $X$ e o resto num $Y$. O $\alpha$ que minimiza o risco depende de variâncias e covariância desconhecidas, que se estimam dos dados. O bootstrap diz quanto esse $\hat\alpha$ é confiável.

> [!warn] Uma amostra bootstrap contém, em média, só cerca de **dois terços** das observações originais distintas (a chance de uma observação entrar é $1-(1-1/n)^n\approx0{,}632$). Por isso o bootstrap não serve para estimar o erro de teste: pontos "de fora" aparecem no treino.

> [!lab] **Para o caderno.** [CV em classificação e o bootstrap](/l/ch05-cv-classif-bootstrap): calcule o erro-padrão bootstrap e a probabilidade de uma observação entrar na amostra.

> [!deep] **No livro.** O laboratório (pp. 215–223) mostra validação cruzada e bootstrap em Python com o pacote `ISLP`.

## Vocabulário

| Termo | Em palavras simples |
|---|---|
| Validação | Parte dos dados guardada só para medir o erro |
| LOOCV | Deixar uma observação de fora por vez |
| K-fold | Dividir em $k$ grupos, usando cada um como teste uma vez |
| Bootstrap | Sortear com reposição para medir incerteza |
| Amostra bootstrap | Nova amostra de tamanho $n$ sorteada dos dados |
| Erro-padrão bootstrap | Desvio-padrão da estimativa entre as amostras bootstrap |
